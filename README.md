**esp32_Navigation** 是一个面向 **步行、自行车/骑行、摩托车、小汽车驾车通勤** 等全场景出行人群的便携式 ESP32 随行智能导航与互联副屏开源系统。

本项目脱离原 MotoNav 的单一摩托车叙事与像素风设计，全面转向**现代化、简洁实用、高质感**的现代交互风格（深度对齐现代音乐播放器、iOS 系统级毛玻璃与平滑抗锯齿矢量渲染引擎），旨在打造一个跨场景、通用、优雅的随行智能信息中心。

> **独立维护说明**：鉴于上游原项目已停止更新，本项目已在 GitHub 建立全新独立仓库 `esp32_Navigation` 进行独立演进与长期维护。  
> **多端与硬件对齐**：本项目固件以 **M5Stack Stopwatch**（1.75 英寸 466×466 AMOLED 圆屏）为首发主力硬件，同时向**微雪（Waveshare 1.75）圆屏固件**及 **iOS 端 App** 完成了代码与逻辑级的架构对齐。  
> ⚠️ **测试声明**：因维护者**缺乏微雪实机硬件与 iOS 编译/真机调试环境**，目前微雪 1.75 固件及 iOS 端 App 未进行实机路测，欢迎广大社区开发者参与测试与贡献 PR！

## 核心特性与设计革新

### 1. 全场景通用出行与双地图引擎
- **双地图引擎适配（国内+出海国际化）**：
  - **高德地图（AMap）**：国内首选，深度支持复杂车道线、电子眼限速与拥堵路况；
  - **OpenStreetMap / Mapbox**：基于全球开源 WGS-84 标准坐标，出海及海外出行无障碍，免商业 Key 限制；
- **多出行方式自由切换**：支持小汽车驾车通勤（多路线智能避堵/高速切换）、自行车/骑行直达、步行导航，以及摩托车专属算路与高德路线分享导入；
- **电子路牌与巡航模式**：无需设置目的地也可一键开启巡航，小地图实时随动、超速提醒、电子眼及安全路段提示；
- **全自动行程轨迹记录**：真实出行自动静默记录 GPS 轨迹并保存在手机本地，支持随时回放与导出标准 GPX 文件。

### 2. 告别像素风 —— 现代简洁实用 UI 体系
- **平滑抗锯齿矢量渲染**：全面摒弃粗糙的 8-bit 像素点阵与高饱和荧光配色，采用亚像素平滑矢量引擎与现代无衬线排版；
- **暗黑微光与现代卡片质感**：背景采用深邃曜石黑搭配程序化矢量道路网络，辅以 16~24dp 优雅圆角胶囊（Capsule）、磨砂玻璃质感底座与精细柔和边界；
- **手机 App 现代风格对齐**：Android 端与 iOS 端全新重塑为现代深色卡片布局与原生毛玻璃视觉，科技深空蓝与红宝石心形配色，与圆屏端高度统一。

### 3. 精致圆屏交互与功能矩阵
- **待机主页（Waiting Dashboard）**：
  - 微光矢量地图背景与大号平滑抗锯齿数字时钟/日期；
  - 常用地点抽屉（★）：轻触一键展开手机同步的常用收藏地与历史目的地，免掏手机即刻算路启程。
- **现代音乐播放器（Music Player）**：
  - 滑动封面飞出切歌与黑胶底托动效；
  - 轻触封面中心播放/暂停（内置 140ms 触控滤波防抖）；
  - 连续快速双击封面或轻触底座，点亮红宝石心形 Like 收藏（双向实时状态同步）；
  - iPhone 风格中央毛玻璃音量调节 HUD（侧边滑动调音，屏幕中央呈现精致半透明胶囊卡片、矢量喇叭与动态声波，1.5 秒自动淡出）。
- **车身姿态与 G-Meter 仪表**：
  - 适配板载 BMI270 姿态传感器，全矢量实时显示倾角与加减速/转向 G 矢量轨迹球；
  - 车规级奢华柔和配色（薄荷青绿安全区 / 落日暖金预警区 / 珊瑚红极限区），支持长按零点校准与双击重置极值。
- **独立圆屏专属设置（Settings Page）**：
  - 左滑即达，无需手机即可轻触调节屏幕亮度（25%/50%/75%/100%）、地图风格（VICE/DARK/CLEAN/RADAR）、屏幕旋转方向（0°/90°/180°/270°）及待机休眠策略。
- **伴侣模式与智能电源管理**：
  - 移植 KK 动态程序化表情角色，支持触控抚摸与震动反馈；
  - 硬件级真关机：无 BLE 连接满 2 分钟自动调用 M5PM1 芯片彻底断电关机，彻底杜绝离线待机跑电。

## 快速上手与固件获取

### 1. 固件烧录（推荐 M5Burner）
- **推荐方式**：本项目固件已发布至 **[M5Burner](https://burner.m5stack.com)**，在 M5Burner 中搜索 `esp32_Navigation` 或 `Stopwatch` 即可一键下载并烧录到 M5Stopwatch。
- **开发者源码编译**：本项目固件使用 PlatformIO 开发，环境为 ESP32-S3：
  ```bash
  pio run -e stopwatch -t upload
  ```

### 2. 手机端配套 App 说明

圆屏设备通过 BLE 低功耗蓝牙与手机 App 互联，由手机完成高德导航算路、媒体信息抓取并低延迟推流至圆屏。

#### 安卓端（Android）全场景 App

##### 🌟 方式一：极速免编译打包（小白用户强烈推荐，零环境、2秒出包）
无需下载几百兆编译环境，无需安装 Android Studio 或配置 SDK：
1. **下载小白发布包**：前往 [Releases 页面](../../releases) 下载 `esp32_Navigation-QuickPack-Windows.zip` 并解压；
2. **一键生成专属包**：双击运行解压目录下的 `一键生成专属安装包.bat`；
3. **极速完成**：工具将在 **2 秒钟** 内自动生成当前电脑专属的 `esp32_Navigation-personal.apk` 及 `高德Key申请信息.txt`；
4. **获取免费 Key**：按照文本指引前往[高德开放平台](https://console.amap.com/)粘贴包名与 SHA1 获取 Android Key，安装 App 后填入即可开箱使用！
5. **升级平滑**：后续升级新版本底包覆盖运行即可，签名自动复用，**无需重新申请高德 Key**。

##### 🛠️ 方式二：全源码本地打包（面向开发者）
#### 安卓端（Android）
- **小白用户极速安装 (推荐)**：前往本仓库 [Releases 页面](https://github.com/nongxl/esp32_Navigation/releases) 下载 `esp32_Navigation-QuickPack-Windows.zip`，解压后双击运行 **`一键生成专属安装包.bat`**，2秒即可生成专属安装包 `esp32_Navigation-personal.apk` 及独立包名与 SHA1，完全无需配置 Java、Android Studio 或编译环境！
- **开发者本地源码打包**：
  1. 双击根目录的 `一键打包-普通版.bat`（或在 PowerShell 中运行 `.\Build-Personal.ps1`）；
  2. 脚本自动检测环境并完成 Gradle 编译，产物位于 `output/` 目录；
  3. 开发者可运行 `导出小白极速发布包.bat` 一键生成供发布给小白用户的免编译分发包。

## 实体双按键操作说明（以 M5Stopwatch 为例）

| 按键动作 | 主界面下行为 | 其他页面 / 导航中行为 |
| :--- | :--- | :--- |
| **短按左键 (KEY A)** | 向左滑入音乐播放页 | 快速返回主界面 |
| **短按右键 (KEY B)** | 向右滑入圆屏设置页 | 快速返回主界面 |
| **长按左键 (KEY A，≥500ms)** | 全局上一曲（带震动反馈） | 全局上一曲（带震动反馈） |
| **长按右键 (KEY B，≥500ms)** | 全局下一曲（带震动反馈） | 全局下一曲（带震动反馈） |
| **双键同时长按 (A + B，≥800ms)** | 切换【主导航】与【倾角/G值仪表】 | 伴侣模式下快速退出 |
